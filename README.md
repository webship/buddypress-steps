# buddypress-steps

Cucumber step definitions for BuddyPress, the community plugin of WordPress (member profiles, the activity stream,
friends, groups, private messages and notifications), with [webship-js](https://webship.co/docs/webship-js/2.0.x), a
BDD browser automation harness built on Playwright and Cucumber-js.

The steps, their features, the test site and CI come with the first release, `2.0.0`.
